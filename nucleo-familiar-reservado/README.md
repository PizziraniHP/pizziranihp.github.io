# Projeto Luna – Árvore Genealógica Inversa

Este projeto tem como objetivo registrar e apresentar a árvore genealógica da família Pizzirani em uma estrutura de pirâmide inversa. A página foi desenvolvida para ser um legado para as futuras gerações, permitindo que elas conheçam suas raízes e a história de seus antepassados.

## Estrutura do Projeto

O projeto é composto pelos seguintes arquivos e pastas:

- **index.html**: O arquivo principal que contém a estrutura HTML da árvore genealógica. Inclui seções para introdução, curiosidades e a pirâmide inversa, além de um lightbox para visualização de imagens.
  
- **style.css**: Este arquivo contém os estilos CSS que definem a aparência da página, incluindo layout, cores, fontes e estilos para os elementos da árvore genealógica.
  
- **script.js**: Contém o código JavaScript que implementa a funcionalidade do lightbox, permitindo que as imagens sejam exibidas em tamanho maior quando clicadas.
  
- **imagens/**: Pasta destinada a armazenar os arquivos de imagem utilizados na árvore genealógica, como fotos de familiares.

## Como Usar

1. **Clone o repositório** ou faça o download dos arquivos.
2. **Abra o arquivo `index.html`** em um navegador para visualizar a árvore genealógica.
3. **Adicione novas informações** e imagens conforme necessário, editando os arquivos `index.html`, `style.css` e `script.js`.
